## 📒 Miniguia de Estudo

### Resumos Estruturados
- **Data Lake:** Repositório de dados brutos, flexível e barato.  
- **Data Warehouse:** Estrutura otimizada para consultas analíticas.  
- **Data Lakehouse:** Combinação dos dois mundos, unindo flexibilidade e performance.  
- **Orquestração:** Ferramentas como Airflow e Prefect para gerenciar pipelines.  

### Glossário
- **ETL:** Extract, Transform, Load  
- **Pipeline de Dados:** Fluxo automatizado de ingestão e processamento  
- **Governança de Dados:** Práticas para garantir qualidade e segurança  

### Prompts Reutilizáveis
- "Explique a diferença entre Data Lake, Data Warehouse e Lakehouse."  
- "Liste ferramentas modernas de orquestração de dados e seus casos de uso."  
- "Quais são os principais desafios de escalabilidade em pipelines de dados?"
